# Skill

## Versión

1

## Qué es

Una **skill** es una instrucción versionada (markdown) que un agente sigue para hacer un trabajo concreto: descubrir un negocio, mapear un recorrido, generar un script o diagnosticar una alerta.

## Cómo se guarda

- Índice en `catalogo/skills/index.json`.
- Cada versión en `catalogo/skills/<id>/vN.md`.
- Editar en la UI crea una versión nueva; no pisa la anterior.

## Relación con anclas y proyectos

Una skill declara las anclas que usa. Un **proyecto** puede agrupar varias skills (many-to-many).

# Campo ancla

## Versión

1

## Qué es

Un **campo ancla** es un dato con nombre fijo que el sistema espera encontrar en el recorrido o en el resultado de una skill. Se escribe como `_ruta.del.campo_` y es lo único que el código extrae de forma automática.

## Para qué sirve

- Une la skill, MongoDB y el negocio con la misma clave.
- Evita inventar nombres: el catálogo Campos ancla es la lista canónica.
- En el markdown de una skill, la tabla «Campos ancla» lista qué valores debe rellenar el agente.

## Ejemplo

`_negocio.nombre_` — nombre comercial del local, tal como lo ve el cliente.

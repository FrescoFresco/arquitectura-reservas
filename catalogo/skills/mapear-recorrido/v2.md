# Mapear recorrido

## Versión

2

## Instrucción

Recorre la web de reserva del negocio desde el punto A (`proceso.url_inicio`) hasta el punto B y descríbelo con los campos ancla.

- **B** es el formulario relleno, sin errores de validación y con el botón de confirmar a la vista, justo antes de enviar.
- **Nunca pulses el botón de confirmar ni envíes nada.** Si un botón intermedio pudiera enviar la reserva, no lo pulses y explícalo.
- Rellena con datos de prueba evidentes (nombre «Prueba», email en `example.com`, teléfono +34 600 000 000). Usa una fecha de dentro de unos días, nunca hoy, y una hora dentro del horario del local.
- Averigua qué sistema de reservas hay detrás (CoverManager, TheFork, plugin WordPress, formulario propio…) y anota qué lo demuestra.
- Para cada campo del formulario, di si es obligatorio y cómo lo sabes. Usa selectores de Playwright estables.
- Si aparece un obstáculo (CAPTCHA, login, pago), **no lo esquives**: anótalo y para ahí.
- Si ves el mensaje de «sin hueco», cópialo literal. Si no lo ves, escribe `null`.

## Entrada

| Campo | Tipo | Descripción |
|---|---|---|
| `negocio.nombre` | texto | Nombre comercial del local. |
| `negocio.url` | url | Web principal del local. |
| `negocio.zona_horaria` | zona_horaria | Zona horaria IANA del local. |
| `negocio.telefono` | telefono | Teléfono público del local. |
| `proceso.url_inicio` | url | Punto A: URL donde empieza la reserva. |
| `proceso.alcance` | enum | hasta_B o completo. |

## Reglas de anclaje

- Escribe solo los campos de la tabla «Campos ancla», uno por línea: `_ruta.del.campo_: valor`.
- En las listas, sustituye `N` por 1, 2, 3… sin huecos.
- `null` si no hay dato; nunca inventes.
- Textos largos: valor vacío y el texto entre tres comillas invertidas.

## Campos ancla

| Campo | Tipo | Descripción |
|---|---|---|
| `proceso.url_inicio` | url | Punto A confirmado. |
| `version.recorrido.sistema.nombre` | texto | Sistema de reservas. |
| `version.recorrido.sistema.evidencia` | texto_largo | Qué lo demuestra. |
| `version.recorrido.llega_a_b` | booleano | true si se llegó a B. |
| `version.recorrido.pasos.N.accion` | texto | Acción del paso. |
| `version.recorrido.pasos.N.selector` | texto | Selector Playwright. |
| `version.recorrido.campos.N.nombre` | texto | Etiqueta del campo. |
| `version.recorrido.campos.N.selector` | texto | Selector único. |
| `version.recorrido.campos.N.obligatorio` | booleano | true si es obligatorio. |
| `version.recorrido.boton_confirmar.selector` | texto | Selector del botón de confirmar. |
| `version.recorrido.mensaje_sin_hueco` | texto_largo | Mensaje sin disponibilidad. |

## Resultado

1. `## Explicación`
2. `## Salida` con líneas `_ruta.campo_: valor`

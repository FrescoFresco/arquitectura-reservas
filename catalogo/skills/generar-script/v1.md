# Generar script

## Versión

1

## Instrucción

A partir del recorrido de la Entrada, escribe a la vez el script de Playwright y el JSON Schema de los parámetros de su función.

El script es un módulo JavaScript sin `import`, con dos funciones exportadas:

```js
export async function hastaB(page, params, registrar) { … return { estado, referencia, alternativas, motivo }; }
export async function confirmar(page) { … }
```

- Cuando se llama a `hastaB`, el ejecutor ya ha abierto `proceso.url_inicio` en `page`.
- `hastaB` sigue los pasos del recorrido, rellena el formulario con `params` y se para en B. **Nunca pulsa el botón de confirmar.**
- Llama a `registrar('…')` en cada paso, con frases cortas en español.
- `confirmar(page)` solo pulsa el botón de confirmar; el ejecutor solo la llama con la compuerta abierta.

## Entrada

| Campo | Tipo | Descripción |
|---|---|---|
| `negocio.zona_horaria` | zona_horaria | Zona horaria IANA del local. |
| `proceso.url_inicio` | url | Punto A. |
| `version.recorrido.sistema.nombre` | texto | Sistema de reservas. |
| `version.recorrido.pasos.N.accion` | texto | Acción del paso. |
| `version.recorrido.pasos.N.selector` | texto | Selector Playwright. |
| `version.recorrido.campos.N.selector` | texto | Selector del campo. |
| `version.recorrido.boton_confirmar.selector` | texto | Selector del botón de confirmar. |

## Reglas de anclaje

- Escribe solo los campos de la tabla «Campos ancla», uno por línea: `_ruta.del.campo_: valor`.
- El script y el JSON Schema son textos largos: valor vacío y el texto entre tres comillas invertidas.

## Campos ancla

| Campo | Tipo | Descripción |
|---|---|---|
| `version.script` | texto_largo | Módulo con hastaB y confirmar. |
| `version.funcion.nombre` | texto | Nombre snake_case de la función. |
| `version.funcion.parametros` | json | JSON Schema de los parámetros. |

## Resultado

1. `## Explicación`
2. `## Salida` con `_version.script_:`, `_version.funcion.nombre_:` y `_version.funcion.parametros_:`

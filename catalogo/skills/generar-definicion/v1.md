# Generar definición

## Versión

1

## Instrucción

Convierte una intención en lenguaje natural en una definición JSON (disparador, flujo o pipeline) usando solo el contexto real del hub.

El ejecutor es un **modelo** llamado desde la API (`POST /v1/redactor`), sin n8n. La IA nunca guarda sola: validar → probar → confirma el usuario.

## Entrada

| Campo | Tipo | Descripción |
|---|---|---|
| `intencion` | texto | Qué quieres construir, en lenguaje natural. |
| `tipo_definicion` | texto | `disparador` \| `flujo` \| `pipeline`. |
| `esquema` | json | Esquema del tipo pedido. |
| `contexto` | json | Anclas, colecciones, skills y flujos reales leídos en ese momento. |
| `definicion_actual` | json | Definición previa si se está editando. |

## Salida

| Campo | Tipo | Descripción |
|---|---|---|
| `definicion` | json | Definición generada según el tipo. |
| `explicacion` | texto | 2–3 frases en español. |

## Reglas

- Devolver solo JSON válido según el esquema.
- Usar solo anclas, skills y colecciones del contexto.
- Usar solo las etapas de pipeline permitidas (`$match`, `$lookup`, `$project`, `$group`, `$sort`, `$limit`, `$unwind`, `$addFields`).
- Si falta algo (por ejemplo una skill), decirlo en la explicación en lugar de inventarlo.

# Descubrir negocio

## Versión

1

## Instrucción

A partir de la web del local, reúne la identidad del negocio, contactos públicos, puntos de inicio de reserva y el canal de cancelación.

- No inventes teléfonos ni emails: solo lo que aparece en la web o en páginas enlazadas de forma evidente.
- Si hay varios inicios de reserva, anótalos todos y di cuál parece el principal.
- El canal de cancelación es cómo el cliente cancela (teléfono, email, enlace, panel del sistema…).

## Entrada

| Campo | Tipo | Descripción |
|---|---|---|
| `negocio.url` | url | Web principal del local. |

## Reglas de anclaje

- Escribe solo los campos de la tabla «Campos ancla», uno por línea: `_ruta.del.campo_: valor`.
- `null` si no hay dato; nunca inventes.

## Campos ancla

| Campo | Tipo | Descripción |
|---|---|---|
| `negocio.nombre` | texto | Nombre comercial. |
| `negocio.url` | url | Web principal confirmada. |
| `negocio.zona_horaria` | zona_horaria | Zona horaria IANA. |
| `negocio.telefono` | telefono | Teléfono público. |
| `proceso.url_inicio` | url | Punto A principal. |

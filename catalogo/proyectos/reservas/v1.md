# Software de reservas

## Qué es

Proyecto **software** (no un negocio). Tiene su propia base MongoDB `software_reservas`, diagrama de colecciones y agentes con permisos de lectura/escritura sobre anclas.

Los negocios (Pelo Sur, La Mesa Norte, …) son **documentos** de la colección `negocios`, no proyectos.

## Base de datos

`software_reservas`

## Colecciones

- `negocios` — un documento por negocio cliente
- `procesos` — puntos A / alcances
- `versiones` — recorridos, scripts y funciones
- `reservas` — reservas hechas por los agentes
- `ejecuciones` — historial de ejecuciones
- `reservas_prueba` — reservas de prueba

## Skills compartidas

Las skills siguen siendo del catálogo global; este proyecto las asocia por id.

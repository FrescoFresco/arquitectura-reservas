# Software de llamadas

## Versión

1

## Qué es

Esquema de base de datos para el software de **llamadas**: una base Mongo propia (`software_llamadas`) con cajones `clientes` y `llamadas`.

## Colecciones

- `clientes` — nombre y teléfono
- `llamadas` — fecha, resultado (`contesto` | `no_contesto` | `cita`) y `cliente_id`

## Relaciones

- `llamadas.cliente_id` → `clientes._id` (N:1)

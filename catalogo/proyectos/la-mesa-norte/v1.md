# La Mesa Norte

## Versión

1

## Qué es

Proyecto de acoplamiento a la web de reservas de **La Mesa Norte**: descubrir el negocio, mapear el recorrido hasta B, generar el script de Playwright y diagnosticar alertas cuando la vigilancia falle.

## Skills

Este proyecto usa las skills del catálogo compartido:

- `descubrir-negocio` — identidad, contactos y punto A
- `mapear-recorrido` — formulario y pasos hasta B, sin confirmar
- `generar-script` — Playwright y esquema de parámetros
- `diagnosticar-alerta` — causa del fallo y skill a relanzar

## Notas

Una skill puede pertenecer a varios proyectos. Las asociaciones viven en el índice del proyecto (`skills`), por id de skill.

Atlas (recomendado)
-------------------
1. Crea o abre la base arquitectura_reservas
2. Add Data → Import JSON/CSV file
3. Elige la colección (p. ej. negocios) y el archivo negocios.json
4. Repite para cada archivo del ZIP

Compass
-------
1. Conecta al cluster y abre arquitectura_reservas
2. Crea la colección si no existe
3. Collection → Import data → elige el .json de esa colección
4. Repite para las 10 colecciones

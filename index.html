                Conexión
                

                
Sin configurar


                

                

                

                

                

                

                Cadena de conexión Atlas (mongodb+srv://…) de este cluster. La comparten todas las Bases de datos vinculadas. No es una API key de administración de Atlas ni el invite de agente. Queda cifrada; el panel no la vuelve a mostrar. Sin URI, las operaciones Mongo de las bases de este cluster fallan (no hay URI global en Ajustes).
                

                
Sin configurar

                La URI guardada no se vuelve a mostrar.
                

                

                


                




                

                

                

                


                Opt-in. Si está activo y hay URI, al crear/editar/borrar Campos o al cambiar colecciones, relaciones o baseDatos de una Base de este cluster, el Worker empuja el DDL a Atlas (mismo camino que Empujar), con un retardo corto para agrupar ediciones rápidas. Unidireccional hub→Atlas; no borra colecciones remotas. Sin URI hace dry-run y deja el resultado abajo. Empujar manual sigue disponible.

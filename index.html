    Conectar un agente

    Empieza leyendo Documentación → API (https://frescofresco.github.io/arquitectura-reservas/) y el contrato que ya está en el repo. No inventes rutas.

    El token se obtiene con el botón Generar token. La primera vez confirmas en GitHub con la cuenta que puede escribir en FrescoFresco/arquitectura-reservas. En este navegador, los clics siguientes emiten otro token sin volver a GitHub. El token dura 1 hora. Pégalo solo en el agente.

    Puede modificar: Skills (documento o versión), Campos ancla, Campos MongoDB y Proyectos. Cada publicación es una versión nueva y no pisa la anterior. También puede eliminar una skill. La confirmación solo está en la página; la API elimina directo cuando el agente lo pide.

    En Skills: Editar modifica el contenido y guarda una versión nueva; Subir versión carga un documento completo como versión nueva.

    El cliente de referencia es scripts/subir.js. Lee el índice antes de escribir.

    El token dura 1 hora.

    Pégalo en el agente, en GITHUB_TOKEN, y pulsa Enviar.

    Un agente publica con la API de contenidos de GitHub. El token se obtiene con Generar token, en Conectar un agente, dura 1 hora y va en el entorno (GITHUB_TOKEN o GH_TOKEN). No se guarda en esta página.

    Repositorio FrescoFresco/arquitectura-reservas. Rama main. Cada publicación son dos escrituras: primero el archivo y después el índice, con el sha que devolvió el GET.

    Subir un documento a Skills

    El catálogo se llama Skills. El id interno es skills y la carpeta es catalogo/skills/. No hay otro catálogo de instrucciones al lado.

    Ejemplo: una skill nueva, «Mapear recorrido», id mapear-recorrido, archivo mapear-recorrido.md.

    1. Crear el archivo. Un archivo nuevo no lleva sha. Si la ruta ya existe, el cuerpo incluye el sha del GET de esa misma ruta.

    PUT https://api.github.com/repos/FrescoFresco/arquitectura-reservas/contents/catalogo/skills/mapear-recorrido/v1.md

    Cabeceras:

    • Authorization: Bearer TOKEN
    • Accept: application/vnd.github+json
    • X-GitHub-Api-Version: 2022-11-28
    {
  "message": "Añade mapear-recorrido v1 a Skills",
  "content": "BASE64_DEL_ARCHIVO",
  "branch": "main"
}

    2. Leer el índice. La respuesta trae sha y el JSON en content (base64).

    GET https://api.github.com/repos/FrescoFresco/arquitectura-reservas/contents/catalogo/skills/index.json?ref=main

    3. Añadir la versión y volver a escribir el índice con ese sha.

    PUT https://api.github.com/repos/FrescoFresco/arquitectura-reservas/contents/catalogo/skills/index.json
    {
  "message": "Actualiza el índice de Skills",
  "content": "BASE64_DEL_JSON",
  "branch": "main",
  "sha": "SHA_DEL_GET"
}

    El JSON queda así. La skill nueva entra en instrucciones. Una versión nueva se añade al array versiones de esa skill. numero es el máximo actual más uno. fecha es YYYY-MM-DD. ruta es relativa a la raíz del sitio. Opcional: descripcion (texto corto) y anclas (lista de nombres completos como _negocio.nombre_).

    {
  "id": "skills",
  "nombre": "Skills",
  "instrucciones": [
    {
      "id": "mapear-recorrido",
      "nombre": "Mapear recorrido",
      "descripcion": "Recorre la web de reserva desde A hasta B.",
      "anclas": ["_negocio.nombre_", "_proceso.url_inicio_"],
      "versiones": [
        {
          "numero": 1,
          "fecha": "2026-10-20",
          "ruta": "catalogo/skills/mapear-recorrido/v1.md",
          "nombreArchivo": "mapear-recorrido.md"
        }
      ]
    }
  ]
}

    Vale cualquier tipo de archivo. La página pinta markdown (.md, .markdown, .txt). El resto se descarga.

    Otra versión de la misma skill, por ejemplo un PDF:

    PUT https://api.github.com/repos/FrescoFresco/arquitectura-reservas/contents/catalogo/skills/mapear-recorrido/v2.pdf
    {
  "numero": 2,
  "fecha": "2026-10-20",
  "ruta": "catalogo/skills/mapear-recorrido/v2.pdf",
  "nombreArchivo": "mapear-recorrido.pdf"
}

    El id solo usa minúsculas, números y guiones: ^[a-z0-9][a-z0-9-]{0,60}$.

    Eliminar una skill

    En la página, Eliminar está en la tarjeta. Pregunta «¿Estás seguro de eliminar la skill?» con Confirmar y Cancelar. Cancelar cierra. Confirmar quita esa skill y sus versiones de la lista de este navegador. La API no pregunta: cuando el agente lo pide, borra la skill del índice. No se añade una versión ni se escribe otro archivo.

    1. Leer el índice. La respuesta trae sha y el JSON en content (base64).

    GET https://api.github.com/repos/FrescoFresco/arquitectura-reservas/contents/catalogo/skills/index.json?ref=main

    2. Quitar ese objeto de instrucciones y volver a escribir el índice con ese sha.

    PUT https://api.github.com/repos/FrescoFresco/arquitectura-reservas/contents/catalogo/skills/index.json
    {
  "message": "Elimina mapear-recorrido de Skills",
  "content": "BASE64_DEL_JSON",
  "branch": "main",
  "sha": "SHA_DEL_GET"
}

    Publicar el índice de Campos ancla

    El catálogo Campos ancla vive en catalogo/campos-ancla/index.json. Cada campo lleva ancla (p. ej. _negocio.nombre_), etiqueta, enlace Mongo (claveMongo, coleccion, baseDatos), tipo, obligatorio, formato, descripcion, ejemplo y skills (ids de skills que lo usan).

    GET https://api.github.com/repos/FrescoFresco/arquitectura-reservas/contents/catalogo/campos-ancla/index.json?ref=main
    PUT https://api.github.com/repos/FrescoFresco/arquitectura-reservas/contents/catalogo/campos-ancla/index.json
    {
  "message": "Actualiza Campos ancla",
  "content": "BASE64_DEL_JSON",
  "branch": "main",
  "sha": "SHA_DEL_GET"
}

    Publicar el índice de Campos MongoDB

    El catálogo Campos MongoDB vive en catalogo/campos-mongodb/index.json. Cada campo lleva campo (p. ej. negocios.nombre), baseDatos, coleccion, clave, bsonType, obligatorio, descripcion y ancla (enlace al catálogo Campos ancla).

    GET https://api.github.com/repos/FrescoFresco/arquitectura-reservas/contents/catalogo/campos-mongodb/index.json?ref=main
    PUT https://api.github.com/repos/FrescoFresco/arquitectura-reservas/contents/catalogo/campos-mongodb/index.json
    {
  "message": "Actualiza Campos MongoDB",
  "content": "BASE64_DEL_JSON",
  "branch": "main",
  "sha": "SHA_DEL_GET"
}

    Cliente de referencia

    scripts/subir.js hace esas escrituras. El token sale del entorno. skills escribe en la carpeta de Skills. Con --eliminar solo vuelve a escribir el índice: quita la skill y no deja una versión nueva.

    GITHUB_TOKEN=TOKEN node scripts/subir.js skills --nueva --nombre "Mapear recorrido" --archivo ./mapear-recorrido.md
GITHUB_TOKEN=TOKEN node scripts/subir.js skills --id mapear-recorrido --archivo ./mapear-recorrido.md
GITHUB_TOKEN=TOKEN node scripts/subir.js skills --eliminar --id mapear-recorrido

    --ensayo muestra la ruta y el índice sin llamar a GitHub. GITHUB_REPOSITORIO (por defecto FrescoFresco/arquitectura-reservas) y GITHUB_RAMA (por defecto main) cambian el destino.
